# Plus-Size Beauty

This is a mobile-friendly beauty affiliate storefront and app-style landing page for Plus-Size Beauty.

## Included
- Responsive storefront homepage
- Affiliate and social links
- Media section
- QR code generation for the live page
- Mobile app install support with a PWA manifest and service worker
- No photo replacements were made; the visual style keeps the original imagery and palette

## Deploy to GitHub Pages
1. Push this repo to GitHub
2. Go to repo settings
3. Open Pages
4. Set Source to GitHub Actions or root branch if preferred
5. Publish your site

## QR code
The QR code is generated automatically on the page using the current site URL and can be downloaded as a PNG.

## Install as app
On a mobile device, use the browser menu and choose "Install App" or "Add to Home Screen" when available.

## Recommended live URL
Once published, the QR code will point to your live site automatically.
